# Finance Tracker 💰

A full-stack web application that helps users understand and improve their spending habits by analyzing bank statements and providing intelligent financial insights.

## 🚀 Features (Planned)
Upload bank statements (CSV/PDF)
Automatic transaction parsing
Smart spending categorization
Interactive dashboard (charts & trends)
Budget planning tools
AI-powered financial insights

## 🧠 Motivation
Managing personal finances can be difficult, especially when trying to understand where money is going.
This project was built to solve that problem by turning raw bank data into clear, actionable insights.

## 🏗️ Tech Stack
### Frontend
- React (planned)
- Tailwind CSS (planned)

### Backend
- Python (Flask)
- Pandas (data processing)

### Database
- PostgreSQL (planned)
